# Applied Optimization — HandsOn

This folder contains hands-on notebooks and example code used in the Applied Optimization course.

Purpose
- Provide practical, notebook-based exercises that illustrate optimization concepts.
- Keep working examples and utilities for assignments and experimentation.

Contents
- `01_unconstrained_and_saddle.ipynb` — unconstrained optimization and saddle points
- `02_semidefinite_and_convexity.ipynb` — semidefinite programming and convexity notes
- `03_equality_constraints_lagrange.ipynb` — equality constraints and Lagrange multipliers
- `common_utils.ipynb` — utility helpers used across notebooks
- `simplex_new_old_cplex.ipynb` — simplex method and CPLEX comparison

Notes
- Files may include exploratory code and draft solutions.
- For overall repository context, see the project root `README.md`.
