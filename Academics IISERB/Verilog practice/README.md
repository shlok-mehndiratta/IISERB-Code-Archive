# Verilog Practice

This folder contains practice code and exercises for Verilog hardware description language.

Purpose
- Archive Verilog modules, testbenches, and small experiments.
- Provide reference implementations for digital design concepts.

Contents
- Example modules: mux, bitwise operations, comparators, timing, and more.
- Subfolder `01-module_interconnection/` for module interconnection examples.

Notes
- Files may include draft or exploratory code.
- See the repository root `README.md` for overall context.
